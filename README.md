Emberfall is a neon arcade survival game: a little ember spirit drifts through the night collecting star shards, chaining combos, dashing through danger and dodging cinders, meteors and sparks. Reach 5,000 points to become Ember Legend. No libraries, no network — plain canvas, ES modules and synthesised WebAudio sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Move with WASD or arrow keys, SPACE dashes, P pauses, M mutes. `?seed=N` fixes a run's randomness; `?shot=start|play|end` stages a screenshot scene.
